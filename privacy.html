プライバシーポリシー

sukkato-shorts uploader ・ 最終更新日：2026年10月18日 ・ English

sukkato-shorts uploader（以下「本ツール」）は、個人の開発者（GitHub: takaya0806、以下「開発者」）が自分の YouTube チャンネルに自作の動画を投稿するためだけに使う個人用プログラムです。一般の利用者に向けたサービスはなく、本ツールが扱う Google アカウントは開発者本人のものだけです。

1. YouTube API サービスの利用

本ツールは YouTube API サービス（YouTube Data API v3）を利用しています。本ツールを使うことは、YouTube 利用規約に同意することを意味します。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。

2. 許可を受けている権限（スコープ）

スコープ目的
https://www.googleapis.com/auth/youtube.upload本ツールが生成した動画をアップロードし、公開日時を予約するため
https://www.googleapis.com/auth/youtube.readonly投稿先チャンネルの確認、二重投稿の防止、投稿した動画の公開状態の確認のため

メールアドレス・氏名・プロフィール写真などの権限（openid・email・profile）は求めていません。

本ツールが生成した動画ファイル（MP4）と、そのタイトル・説明文・タグ・カテゴリ・言語、公開設定（常に「非公開」で送信し、必要に応じて予約公開日時を指定）、「子ども向けではない」設定、埋め込み可否、ライセンス、（設定した場合のみ）改変・合成コンテンツの申告です。動画・文章は開発者が作成したもので、第三者の個人情報は含みません。

行わないこと

  • 動画の削除・編集、コメント、評価、再生回数や収益などの分析データの取得は行いません（そのための権限もありません）。
  • 開発者以外の Google アカウントやチャンネルのデータは扱いません。
  • 取得したデータを販売したり、広告（ターゲティング広告を含む）に利用したり、第三者に提供したりしません。
  • 取得したデータを、汎用的な AI・機械学習モデルの開発・改善・学習のために利用・提供しません。
  • 本ツールに Cookie・アクセス解析・広告タグはありません。

5. 第三者との共有

取得したデータを第三者に販売・提供することはありません。本ツールの動作に必要な範囲で、次のサービスがデータを処理します。

  • Google / YouTube：動画のアップロード先、API の提供元
  • GitHub：プログラムの実行（GitHub Actions）と記録・認証情報の保存（GitHub のプライバシーステートメント）
  • Anthropic：上記のとおり、リポジトリ編集のための開発ツール

法令に基づく開示が求められた場合を除き、これ以外の共有は行いません。

6. アクセス権の取り消しとデータの削除

  1. アクセス権の取り消し：Google アカウントの「サードパーティ製のアプリとサービス」（Google のセキュリティ設定ページ）で本ツールのアクセスを削除すると、リフレッシュトークンは使えなくなり、本ツールは以後 YouTube のデータにアクセスできません。
  2. 認証情報の削除：GitHub リポジトリの Settings → Secrets and variables → Actions で YOUTUBE_CLIENT_ID・YOUTUBE_CLIENT_SECRET・YOUTUBE_REFRESH_TOKEN を削除します。
  3. 記録の削除：uploads/ledger.json・uploads/errors.jsonl の該当部分を削除し、GitHub Actions の実行記録と関連する Issue を削除します。Git の仕組み上、過去のコミットには内容が残るため、完全に消す場合は履歴の書き換えかリポジトリ自体の削除を行います。
  4. 投稿した動画：本ツールには動画を削除する機能がないため、YouTube Studio から削除します。

開発者は、本ツールの利用をやめる場合やアクセス権を取り消した場合、上記の手順で認証情報と記録を削除します。

7. 安全管理

  • 認証情報は GitHub Secrets にのみ保存し、コード・ログ・公開ページには載せません。
  • 投稿前に、認証したアカウントのチャンネル ID が登録値と一致するかを確認し、一致しない場合は投稿を中止します。
  • 通信はすべて HTTPS で行います。

8. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

Privacy Policy (English)

Last updated: October 18, 2026

sukkato-shorts uploader ("the Tool") is a personal program used only by its individual developer (GitHub: takaya0806) to upload the developer's own videos to the developer's own YouTube channel. It is not offered to the public, and the only Google account it handles is the developer's own.

YouTube API Services

The Tool uses the YouTube API Services (YouTube Data API v3). By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

Scopes

  • youtube.upload: upload videos generated by the Tool and schedule their publish time.
  • youtube.readonly: confirm the destination channel, prevent duplicate uploads, and check the status of uploaded videos.

The Tool does not request openid, email or profile.

Data accessed and how it is used

  • Access token and granted scopes (OAuth token refresh): used to call the API; kept in memory only, never written to files or logs.
  • The developer's channel ID, title, custom URL, uploads playlist ID and video count (channels.list, mine=true): used to confirm that the destination matches the registered channel ID (the Tool aborts otherwise) and shown in the run summary. The channel ID is also stored in the upload record.
  • IDs, titles and publish dates of up to 200 recent uploads on the channel, including private and scheduled videos (playlistItems.list): used to skip a script when a video with the same title already exists. Held in memory; only videos that match a script have their ID and title stored in the upload/error records and run summary.
  • Status of videos uploaded by the Tool (privacy status, scheduled time, upload status, failure/rejection reason) and their titles (videos.list): shown in the run summary to confirm scheduling; not written to the upload record.
  • ID of each uploaded video (videos.insert response): stored in the upload record.

Sent to YouTube: the generated MP4 file and its title, description, tags, category, language, privacy status (always "private", optionally with a scheduled publish time), not-made-for-kids setting, embeddable flag, license and, only if enabled, the altered/synthetic content disclosure.

The Tool does not delete or edit videos, read comments or ratings, or access analytics or revenue data. It does not handle any other user's account or channel. Data obtained from Google is not sold, used for advertising, transferred to third parties, or used to develop, improve or train generalized AI/ML models. The Tool uses no cookies, analytics or ad tags.

Storage and retention

  • OAuth client ID, client secret and refresh token: GitHub Secrets of a private GitHub repository (encrypted, masked in logs); never in code or files. Kept until the developer deletes them or revokes access.
  • Upload record (uploads/ledger.json in the private repository, plus commit messages): script ID, script path and hash, video ID, URL, title, channel ID, scheduled time, upload time, duration, result. Kept until the developer deletes it, to prevent duplicates.
  • Error record (uploads/errors.jsonl, and an Issue in the same private repository on failure). Kept until the developer deletes it.
  • GitHub Actions logs and run summaries: retained per the repository's GitHub setting (90 days by default).
  • Generated video files: exist only in the temporary GitHub Actions runner, discarded after each run.

Only the developer can access the private repository. The developer edits the repository with an AI coding tool (Anthropic's Claude Code), which may read these record files while working.

Sharing

Data is not sold or shared, except as processed by Google/YouTube (API provider and upload destination), GitHub (execution and storage; GitHub Privacy Statement) and Anthropic (development tool, as above), or where disclosure is required by law.

Revoking access and deleting data

  1. Revoke the Tool's access on the Google security settings page. The refresh token then stops working.
  2. Delete YOUTUBE_CLIENT_ID, YOUTUBE_CLIENT_SECRET and YOUTUBE_REFRESH_TOKEN from the repository's GitHub Secrets.
  3. Delete the relevant entries in uploads/ledger.json and uploads/errors.jsonl, the Actions runs and related Issues. Past Git commits keep their contents, so complete removal requires rewriting history or deleting the repository.
  4. Uploaded videos are deleted in YouTube Studio; the Tool has no delete function.

When the developer stops using the Tool or revokes its access, the developer deletes the credentials and records as described above.
