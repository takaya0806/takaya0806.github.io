sukkato-shorts uploader

YouTube シリーズ「スカッとLINE劇場」の自動投稿ツール

このツールは、開発者本人が自分の YouTube チャンネルに自分で作った動画を投稿するためだけに使う個人用のプログラムです。一般の方が登録・ログインして使えるサービスやアプリの配布はありません。

何をするツールか

開発者が書き下ろしたフィクションの台本から、チャット画面風の縦型ショート動画（1080×1920）をプログラムで生成し、開発者本人の YouTube チャンネルへ 非公開 の状態でアップロードして、指定した日時に公開されるよう予約します。

  1. 非公開の GitHub リポジトリにある、まだ投稿していない台本を古い順に選ぶ
  2. GitHub Actions（GitHub のサーバー）上で動画を生成し、尺・音声などを自動で検証する
  3. YouTube Data API で投稿先チャンネルを確認したうえで、動画を「非公開＋予約公開」でアップロードする
  4. 投稿した記録（台本ID・動画ID・タイトルなど）を同じ非公開リポジトリに保存し、同じ動画の二重投稿を防ぐ

Google アカウントで許可している権限

権限（スコープ）使いみち
https://www.googleapis.com/auth/youtube.upload生成した動画を開発者本人のチャンネルにアップロードし、公開日時を予約する
https://www.googleapis.com/auth/youtube.readonly投稿先が正しいチャンネルかの確認、同じタイトルの動画がすでにないかの確認、投稿した動画の公開状態の確認

メールアドレスやプロフィールの権限は求めていません。動画の削除・編集、コメント、再生回数などの分析データ、他人のチャンネルの操作は行いません。取得したデータの扱いはプライバシーポリシーに書いています。

About (English)

sukkato-shorts uploader is a personal tool used only by its developer to upload the developer's own programmatically generated, fictional vertical short videos to the developer's own YouTube channel. It is not offered to the public; there is no sign-up and no app to download.

It runs on GitHub Actions. It generates a video from an unpublished script in a private repository, verifies the video, confirms the destination channel, uploads the video as private with a scheduled publish time (publishAt), and records the upload in the private repository to prevent duplicate uploads.

Requested scopes: youtube.upload (upload and schedule videos) and youtube.readonly (confirm the destination channel, check for existing videos with the same title, and check the status of uploaded videos). It does not request email or profile access and does not delete or edit videos, read comments, or access analytics. See the Privacy Policy and Terms of Service.
